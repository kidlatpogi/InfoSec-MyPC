🛒 Cart System Testing Guide

Complete cart functionality for customer dashboard - Real-time updates, add/remove items, and checkout process

✅ Implementation Status: READY FOR TESTING

All cart features have been implemented and are ready to test on the customer dashboard.

🎯 Core Features Implemented

  • Real-time cart count badge in header navigation
  • Add multiple products to cart with custom quantities
  • Slide-in cart drawer with all items displayed
  • Increase/decrease item quantities with +/- buttons
  • Remove individual items with confirmation
  • Live cart total calculation (₱ format)
  • Checkout button (disabled when cart empty)
  • Checkout page with order summary
  • Role-based access (customers only)

🧪 Testing Workflow

  1. Start Server: Make sure PHP development server is running on port 8000
  2. Login as Customer: Create or use existing customer account (not employee/admin)
  3. Browse Products: Navigate to shop/home page to see product listings
  4. Add to Cart: Click "Add to cart" button on products
  5. View Cart: Click the "Cart" button in header to open cart drawer
  6. Modify Quantities: Use +/- buttons to change quantities
  7. Remove Items: Click red "Remove" button to delete items
  8. Checkout: Click "Checkout" button when ready to complete order

📋 Manual Test Checklist

Customer Role Tests:

  • Cart badge shows "0" initially
  • Add product → Badge updates to "1"
  • Add more products → Badge shows total quantity
  • Open cart drawer → See all items listed
  • Each item shows: image, name, variant, price, quantity
  • Click "+" → Quantity increases, total updates
  • Click "−" → Quantity decreases, total updates
  • Click "−" at qty 1 → Confirmation prompt appears
  • Click "Remove" → Confirmation, then item deleted
  • Cart total matches sum of all items
  • Empty cart → Checkout button disabled
  • With items → Checkout button enabled
  • Click Checkout → Navigate to checkout page
  • Checkout page shows all cart items
  • Order total matches cart total

Staff Role Tests (Should NOT see cart):

  • Login as Employee → Cart button hidden
  • Login as Admin → Cart button hidden
  • Login as Superadmin → Cart button hidden
  • Add to cart buttons hidden on all products
⚠️ Important Notes:
  • Cart requires user to be logged in
  • Cart persists in database (not just session)
  • Stock validation prevents over-ordering
  • All actions update in real-time (no page refresh needed)

Frontend Files:

Database Tables:

  • product_variants - Product variants with stock

💡 Troubleshooting

If cart badge doesn't update:

  • Check browser console for errors
  • Verify you're logged in as customer
  • Clear browser cache and reload

If "Add to cart" fails:

  • Ensure product has variants in database
  • Check variant stock is > 0
  • Verify user is authenticated

If checkout button disabled:

  • Cart must have at least 1 item with quantity > 0
  • Try refreshing the cart drawer
